# Security review
- Establish assets, trust boundaries, attack surface and relevant threat scenarios.
- Check authentication, authorisation, validation, output encoding, injection, path traversal, deserialisation and insecure defaults as applicable.
- Review dependencies, permissions, secret handling, logging and sensitive data exposure.
- Prioritise findings by realistic impact and exploitability; include affected files and actionable remediation.
- Distinguish confirmed vulnerabilities from hardening recommendations and assumptions.
- Do not run exploit payloads against live systems or access data outside the authorised scope.
